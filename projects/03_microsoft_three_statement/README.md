# Microsoft Three Statement Model

Portfolio project 03 — implementation in progress.

## Agreed scope

- Company: Microsoft Corporation (MSFT).
- Historical period: exactly ten fiscal years, FY2017–FY2026.
- Forecast period: FY2027–FY2031.
- FY2016 is retained only for opening balances.
- Primary evidence: Microsoft annual reports and SEC filings, with a fixed information cutoff of 8 October 2026.
- Integrated income statement, balance sheet and cash flow statement.
- Segment forecasts, working capital, PPE cohorts, intangible amortization, debt, finance leases, operating leases, taxes, equity and liquidity funding.
- Base, Upside and Downside cases feeding one active forecast.
- Separate Excel views: Equity Research, Investment Banking, Private Equity and FP&A.
- English deliverables and native editable Excel text boxes explaining the calculations.
- Required package: Excel workbook, reproducible Python, explanatory Word report and a portable ZIP archive.

## Portfolio boundaries

This case develops operating forecasts and role-specific interpretations. DCF and Reverse DCF, comparable company analysis and an Equity Research investment thesis are separate subsequent projects. The owner's investment thesis will be elicited through an interview.

A second standalone DCF case will examine another company in an adjacent industry. Similar results will be investigated through explicit assumptions, rather than imposed on the models.

## Data selection

Use the latest comparative statement available at the fixed cutoff for each historical year. Retain the source report year, table and URL for every observation. Distinguish reported values, calculated values, absent cash flow categories and unavailable disclosures.

Segment definitions are not uniform across the entire decade. The current segment definition is available for FY2023–FY2026; growth across the FY2023 definition break must be marked unavailable. Company-wide statements retain the selected reported historical series.

## Completion requirements

Before this project is marked complete, the repository must contain the source snapshot, editable assumptions, Python calculations and checks, the verified Excel workbook, the visually reviewed Word report and the downloadable ZIP. The package must also be placed in the supplied Google Drive folder.

The five substantive scoping questions for this case have already been answered. Before beginning each subsequent project, ask five new questions affecting its specifications and recommend relevant plugins.
